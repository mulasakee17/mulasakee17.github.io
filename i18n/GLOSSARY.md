`KNOWN`, `UNKNOWN`, `CONFLICTED`, `RECOVERING`, `FAILED`, step IDs,
JSON keys, file names, values and URLs are evidence identifiers and remain
unchanged. Original work titles and author names may retain their published
form. Translations must preserve dates, uncertainty, source boundaries and
the distinction between observation, inference and future work.

上述状态、步骤编号、JSON 键、文件名、值与链接是证据标识符，保持原样。
原著标题与作者名可保留出版形式；翻译须保留日期、不确定性、来源范围，
以及观察、推断和未来工作之间的区别。

A technical state such as `COMPLETED` describes software state only. Keep post-hoc analysis, task and seed counts, negative findings, stopped research, and private collection boundaries explicit in both languages.
