Personal Agent Runtime

模型可以提出行动，但授权执行的权力不必属于模型。这项早期工程探索在计划与执行之间设置已注册能力与策略边界，并在执行后核查结果。

这套架构将规划、授权、执行、验证与有界恢复分开。离线验收流程使用模拟客户端；这里提供的是软件证据，未展示真实联网运行。

  1. 模型提出计划
  2. 运行时检查能力与策略
  3. 在边界内执行
  4. 验证后完成或恢复
