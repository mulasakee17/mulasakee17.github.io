从金融预测
走向群体判断的变化。

我最初想让多个 Agent 一起预测、一起决策。后来更吸引我的是：一条新信息进入群体后，谁报告的判断改变了，群体判断又怎样随之变化？

问题怎样变了

让智能体得出一致答案，还不足以解释发生了什么。它们可能看到不同证据，产生分歧，再在讨论中修改自己的报告。我想知道，这些差异怎样影响它们报告的判断；仅凭这些记录，又能对整个过程作出什么判断。

我围绕 Agent 搭建了观察与实验层，再改变它们能看到的信息。后来的检查没有支持一些早期预测假设。我不得不把原先想得太近的三件事分开：观察群体过程、预测结果，以及选择怎样影响它。

留下的实验系统

这项工作建立了一套多智能体实验系统，能够控制信息披露、从同一讨论状态分支进行比较，并保留实际模型运行记录。同时，我也开发了描述群体过程的工具，涵盖信息接触、证据使用、来源记录、响应与资源使用情况。

档案汇集了可复用代码、实验设计与测量约定。我负责研究方向、实验边界及结果解读，AI 协助实现与分析。过程描述器已实现并完成结构检查；其经验效度仍是有待研究的问题。

运行结果说明了什么

使用真实模型的实验发现，信息披露能够改变智能体报告的判断。在涵盖 45 个任务、两个随机种子，并使用 deepseek-chat的事后复现实验中，披露反驳关系时的平均 Brier 损失低于披露支持关系时的损失，但个别任务呈现相反结果。这里测量的是概率报告，并未确立选择干预方式的通用规则。 阅读实验报告。

README 和报告保留了研究方向的变化、否定性发现与实验局限。我已停止 SwarmAlpha 的主动研究，代码和记录仍可用于后续研究与工程移交。
