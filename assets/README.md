# assets

Place your **WeChat QR code** here as:

```
assets/wechat-qr.webp
```

Recommended: a square `.webp`, around 480 × 480 px, with visible quiet
whitespace around the QR so it scans reliably.

Until the file exists, the site shows *"WeChat QR coming soon."* in the
WeChat modal instead of an image.
