*Selected Work

01 Featured Build · Physical AI Prototype / In Development

Moonblade

A Physical Skill Layer for Agentic Intelligence

Today's multimodal AI can recognize what an object is, but often lacks persistent object identity, object-specific context, and the right capabilities for interacting with that particular object.

Moonblade explores a low-cost interface that allows existing physical objects to expose identity, context and relevant skills to AI agents — turning objects from things a model can see into things an agent can work with.

Interaction Attach → Resolve → Load Skill → Interact

Current Goal
Validate whether object-grounded skill injection can outperform generic multimodal AI on real physical tasks.
Initial Scenarios
3D printers · maker-space equipment · laboratory equipment

From object recognition to object-level capability binding.

Project in development — public repository and documentation will follow as validation matures.

02 Featured Research · Multi-Agent Systems Working Research · Paper in Preparation

SwarmAlpha

Information Exposure, Intervention and Governance in LLM Multi-Agent Collective Decision-Making

An experimental research project on how LLM-based multi-agent collectives make decisions — treating information exposure and intervention as governable variables rather than fixed context.

The project is built as open research infrastructure: controlled experimentation, reproducible pipelines, cross-model replication, statistical evaluation, and an audit trail for every run.

Research Question
Can information exposure be treated as an independent governance variable in multi-agent decision-making?
Method
Controlled multi-agent experiments across tasks, intervention conditions and models, with cross-model replication and statistical evaluation.
Evidence
Manifest-verified experiment runs with cross-model replication; findings and stated limitations are documented in the repository.
Status
Working research · paper in preparation
